# Vocab Lens

一个面向英文阅读和托福练习的 Chrome 扩展：选词翻译、保存真实例句，并在之后访问的网页中自动高亮生词。

## 已实现

- 在任意普通网页中选中英文单词或短语，点击浮动的“+ 译”按钮。
- 自动翻译成中文，并可在保存前修改释义。
- 自动提取选词所在句子，同时保存网页标题和 URL；每个词最多保留 5 条不同例句。
- 在之后访问的网页中精确匹配单词或短语并标黄，不区分大小写。
- 悬浮高亮词时显示深色复习卡片；主翻译默认模糊，只在鼠标移入释义区域或提交认识结果后显示。
- “完整释义”展示翻译服务返回的相关译法；旧词首次展开时自动查询并缓存。
- 朗读时播放按钮显示动态音量条，再次点击可停止；可在扩展弹窗中选择系统英文声音。
- “✓”记录认出，“×”记录未认出；“已掌握”会停止网页高亮但保留单词本记录，“删除”会同时移除高亮和单词本记录。
- 单词本可筛选学习中、已掌握、易忘词、最近未认出和从未复习的词，并可把已掌握单词恢复为网页高亮。
- 单词本支持修改释义、朗读、清空统计、删除、手动添加，以及 JSON 导入/导出备份。
- 扩展弹窗提供总开关、网页高亮开关、选词按钮开关和学习概览。

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `vocab-lens`。
5. 刷新已经打开的英文网页。

Chrome 内置页面（如 `chrome://settings`）、Chrome 网上应用店及部分内置 PDF 页面不允许内容脚本运行，这是浏览器的安全限制。

## 使用

1. 在英文网页中选中一个单词或不超过 6 个词的短语。
2. 点击选区旁边的“+ 译”，确认或修改中文释义，然后保存。也可以右键选区，选择“翻译并加入 Vocab Lens”。
3. 再次遇到已保存的词时，它会显示黄色背景。
4. 把鼠标移到这个词上，先回忆意思；再移到模糊区域核对中文释义。
5. 判断一致时点击“✓”，没认出或理解错误时点击“×”。
6. 点击浏览器工具栏里的扩展图标，再点击“打开单词本”查看易忘词。

## 重要限制与隐私

Chrome 扩展无法读取 Chrome 或 Google Translate 自己的原生悬浮窗；它不属于网页 DOM。因此本版本接管了“选词 → 翻译 → 保存”的流程，而不是偷取原生翻译窗中的文字。

当前原型使用 MyMemory Translation API 完成自动翻译。只有你主动选择并点击翻译的文本会发往 MyMemory；翻译结果会在浏览器本地缓存 30 天，浏览过的整页内容和单词本不会上传。匿名接口有每日用量限制，若要发布到 Chrome Web Store，建议替换为：

- 自己的服务端代理 + Google Cloud Translation API；或
- 用户自行配置的正式翻译 API；或
- 本地词典/离线翻译模型。

数据保存在 `chrome.storage.local`，不会自动跨设备同步。请定期从单词本导出 JSON 备份。

## 文件结构

- `manifest.json`：Manifest V3 配置和权限。
- `background.js`：右键菜单及翻译请求。
- `content.js` / `content.css`：选词、例句提取、网页高亮和悬浮复习卡片。
- `popup.*`：工具栏总开关及统计。
- `options.*`：完整单词本管理页。

## 后续适合做的增强

- 词形还原：让 `refer`, `refers`, `referred`, `referring` 归到同一词条。
- 间隔重复：根据错误次数和最近复习时间计算下次出现概率，而不是每次都高亮。
- 同步与账号：加密后同步到自有后端或使用 Chrome Sync（需控制容量）。
- 正式词典数据：展示词性、多义项、音标和英英释义。
- 页面兼容性：针对虚拟列表、Shadow DOM、在线 PDF 阅读器做专项适配。
